# خزانتي

تطبيق ويب (PWA) للآيفون: تصوّر ملابسك، يقص الخلفية ويعرف اللون، ويقترح عليك طقم كل يوم حسب الجو والمناسبة، ويعرضه على مجسم ثلاثي الأبعاد.

- ملف واحد `index.html` + `sw.js` للعمل بدون إنترنت.
- البيانات محفوظة في الجوال فقط (IndexedDB). صدّر نسخة احتياطية من «المزيد».
- الطقس من Open-Meteo (مجاني وبدون مفتاح)، والمجسم بمكتبة three.js.

التثبيت: افتح الرابط في سفاري ← مشاركة ← «إضافة إلى الشاشة الرئيسية».
